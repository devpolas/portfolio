## Code blocks

Add a file name, highlighted lines and line numbers after the language:

```tsx title="app/page.tsx" {2,4-5} showLineNumbers
export default function Page() {
  const name = "docs";

  return (
    <h1>Hello {name}</h1>
  );
}
```

A block with only a language needs nothing else:

```json
{ "name": "portfolio", "private": true }
```
